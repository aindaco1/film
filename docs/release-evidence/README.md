# Release Evidence

Store bounded, non-sensitive release summaries here. Evidence may include public origins, deployment version IDs, command names, pass/fail state, aggregate test counts, migration names, aggregate traffic counts, and configuration mode names.

Do not store operator identities, email addresses or hashes, Resend message IDs, auth links/tokens/cookies/CSRF values, Cloudflare account or namespace IDs, provider credentials, rate-limit identity hashes, raw Wrangler output, private exports, backup bundles, or production record contents.
