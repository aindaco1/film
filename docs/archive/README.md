# Historical Documentation

Historical decisions are consolidated under [the decision index](../adr/README.md). They retain original wording and are not current instructions or readiness claims.

Superseded README, Architecture, Testing and status text is recoverable from Git, including the [beta tag](https://github.com/aindaco1/film/tree/v0.1.0-beta.1). It is not copied into a second current manual.

Dated release/provider acceptance records remain under [Release Evidence](../release-evidence/README.md), because they contain distinct deployment, rollback or live-test evidence. Dated UX reports remain under `docs/design`; their historical findings are not a second backlog. Generated screenshots referenced by those reports are optional local output and may have been cleaned up.
