# Film Architecture

Film follows a static-first app architecture with Worker-owned trust boundaries.

## Repo Shape

- `apps/web`: static TypeScript PWA, no UI framework dependency, with an IndexedDB local mirror, attachment blob staging store, shared presentation/binary/project-summary helpers, and lazily loaded deterministic local-handoff, production-document, production-resource, and screenplay-review serializers.
- `apps/worker`: Cloudflare Worker API for private, sensitive, or stateful behavior.
- `.github/workflows/ci.yml`: provider-secret-free smoke workflow for pull requests and pushes to `main`.
- `packages/schema`: shared TypeScript contracts, seed data, operation validation, and backup helpers.
- `packages/importers`: Notion export preflight, bounded parsing, normalized core/planning import contracts, local mapping helpers, and attachment metadata preservation.
- `packages/providers`: Worker-owned dry-run provider capability and scope contracts.
- `migrations`: D1/SQLite-compatible schema migrations validated by `npm run test:migrations`.
- `docs/RELEASE.md`: release evidence checklist, production gates, and known provider blockers.
- `docs/adr`: architecture decision records.

## Runtime Boundaries

The browser may render local workspace state, capture user intent, keep an IndexedDB mirror with a queued operation log, export local backups, and decrypt encrypted backups for non-destructive previews. It must not own provider credentials, permanent authorization, billing, SMS/email eligibility, sensitive sharing decisions, or final restore commits.

The Worker owns authentication, authorization, provider calls, backup storage handoff, audit events, destructive restore commits, import sanitization, and future collaboration coordination.
